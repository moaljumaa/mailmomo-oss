# Security policy

Please **do not open a public issue** for vulnerabilities. Use GitHub's private vulnerability reporting
(Security tab → "Report a vulnerability") on this repository.

You will get an acknowledgement within 72 hours. Supported version: the latest release.

Mailmomo stores IMAP/SMTP credentials (AES-256-GCM encrypted at rest) and is meant to run behind HTTPS — see the
[security model](README.md#security-model).
